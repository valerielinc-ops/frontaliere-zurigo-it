Descrizione completa

Informazioni sul ruolo Supporta il team ESG Controlling di Zürich/Altstetten nel suo percorso di digitalizzazione e automazione, costruendo e mantenendo applicazioni e datadotti che guidano report ESG automatizzati e scalabili. Attività principale

  • Sviluppo del software: progettazione, costruzione e manutenzione di applicazioni web, che coprono sia lo sviluppo front-end e back-end. Comprendere le esigenze aziendali, tradurli in requisiti tecnici e contribuire al ciclo di vita completo del software dalle specifiche attraverso la distribuzione.

Compito secondario (Nicolo di avere)

  • CI/CD & Infrastructure: Supporta la configurazione e la manutenzione di tubazioni CI/CD per test e distribuzione automatizzati (ad esempio GitHub Actions, Terraform).
  • Ingegneria dei dati & Analytics: Sviluppare e mantenere i flussi di dati e flussi di lavoro in Databricks per supportare i casi di utilizzo di ESG Reporting, tra cui l'ingestione dei dati, la trasformazione e la modellazione.

Le tue abilità ed esperienza Deve avere

  • Esperienza con le moderne tecnologie web e framework (Node.js, Next.js, React) e JavaScript o TypeScript
  • Comprensione di database e SQL
  • Il desiderio di imparare
  • Approccio proattivo
  • Godimento di problem solving
  • Buone capacità di comunicazione e di lavoro di squadra
  • La lingua inglese è richiesta, il tedesco/spagnolo è un plus

Che bello avere

  • Familiarità con concetti e strumenti CI/CD (ad esempio GitHub Actions) e infrastruttura-as-code (ad esempio Bicep, Terraform).
  • Conoscenza o interesse di Databricks, data engineering, Python e workflow di analisi.
  • Conoscenza di PowerBI
  • Familiarità con principi di base API design
  • Comprensione della modellazione dei dati e dbt.
