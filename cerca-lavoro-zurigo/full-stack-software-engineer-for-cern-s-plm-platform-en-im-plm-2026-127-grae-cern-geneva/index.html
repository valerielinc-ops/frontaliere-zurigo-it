Descrizione originale

Ti unirai a un team internazionale nella sezione PLM (Product Lifecycle Management), offrendo soluzioni di gestione delle informazioni ingegneristiche per l'intero complesso di acceleratori e i suoi rivelatori. Questo include la gestione di milioni di documenti di ingegneria, definizioni dei prodotti e modelli CAD (Computer Aided Design). Le tue responsabilità

  • Implementare applicazioni backend utilizzando Java o .NET.
  • Costruire applicazioni web utilizzando tecnologie moderne (React/Electron/Typescript).
  • Integrare le tecnologie di visualizzazione del modello 3D: spettatori web e nativi, realtà virtuale / aumentata.
  • Eseguire le recensioni dei codici, il test, la consegna e il supporto del software.
  • Eseguire l'analisi dei dati e le migrazioni dei dati.
  • Fa parte di un progetto che fornisce ingegneria Digital Twins di installazioni CERN. Maggiori informazioni qui . Il tuo profilo
  • Esperienza e/o forte conoscenza nello sviluppo e nel mantenimento di grandi progetti software utilizzando lo stack .NET o Java Enterprise Edition.
  • Esperienza e/o forte conoscenza con database relazionali come Oracle, PostgreSQL o SQL Server come parte di sistemi su larga scala.
  • Esperienza e/o forte conoscenza nelle pratiche Agile e DevOps in un ambiente di team collaborativo. Competenze
  • Sviluppo backend utilizzando Java o .NET.
  • Sviluppo frontend utilizzando React o Angular.
  • Esperienza con database SQL (ovvero Oracle, SQL Server).
  • Git.
  • Strumenti CI/CD.
  • Parlato e scritto inglese, con un impegno per imparare il francese. Criteri di ammissibilità:
  • Sei un cittadino di uno Stato membro del CERN o di uno Stato membro associato .
  • Con la scadenza dell'applicazione, si dispone di un massimo di due anni di esperienza professionale dalla laurea in Information Technology (o un campo correlato) e la vostra più alta qualifica educativa è sia una laurea o master.
  • Non hai mai avuto un contratto di laurea o di socio del CERN.
  • I candidati senza laurea non sono ammissibili.
  • I candidati con un dottorato non sono ammissibili. Data di chiusura del lavoro: 19.07.2026 alle 23:59 CEST. Durata del contratto: 24 mesi, con una possibile estensione fino a 36 mesi massimo.
