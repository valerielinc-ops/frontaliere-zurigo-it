Descrizione originale

Siamo alla ricerca di un System Engineer con una forte competenza Kubernetes per unirsi al nostro team di consegna del progetto. Questo ruolo si concentra sulla progettazione, l'implementazione e la fornitura di soluzioni basate su Kubernetes per i progetti dei clienti, non sulle operazioni quotidiane o sul supporto alla produzione. Potrai lavorare insieme a project manager, architetti e sviluppatori per portare progetti infrastruttura cloud da concept a deployment. I compiti chiave

  • Progettazione e realizzazione di architetture a cluster Kubernetes per nuovi progetti client (on-premise, cloud o ibrido)
  • Costruire e distribuire piattaforme di applicazioni containerizzate utilizzando Kubernetes, Helm e Operatori
  • sviluppare modelli di infrastruttura-come-codice (Terraform, HCL) per implementazioni Kubernetes ripetibili
  • Configurare sicurezza del cluster, networking (CNI), storage (CSI), e controlli di accesso (RBAC) per ambienti di progetto
  • Integra i Kubernetes con le pipeline CI/CD e i team di applicazioni di supporto durante la consegna dei progetti
  • Collabora con gli architetti di soluzioni per definire le strategie di infrastruttura cloud allineate ai requisiti di progetto
  • Creare documentazione tecnica, diagrammi di architettura e guide di implementazione per la consegna di progetti
  • Eseguire prototipi e implementazioni pilota per convalidare le soluzioni Kubernetes prima dell'implementazione su larga scala
  • Risoluzione dei problemi a livello di progetto durante le fasi di distribuzione e configurazione
  • Supporta workshop e presentazioni tecniche per dimostrare le capacità di Kubernetes

Qualifiche

  • 3+ anni di esperienza nell'ingegneria del sistema, nell'infrastruttura cloud o nei ruoli di project delivery
  • Hands-on esperienza progettazione, costruzione e operativi cluster Kubernetes in ambienti aziendali
  • Forte conoscenza delle tecnologie dei container e piattaforme di orchestrazione (Docker, containerd, Kubernetes)
  • Proficienza in ambienti Linux (RHEL, CoreOS) e scripting di automazione (Bash, Python o Go)
  • Esperienza con Infrastructure come Code (Terraform/HCL) e automazione Kubernetes
  • Familiarità con piattaforme cloud come Oracle Cloud Infrastructure (OCI), AWS o Azure
  • Esperienza con strumenti CI/CD e pratiche DevOps (GitLab CI, Jenkins)
  • Conoscenza delle operazioni di monitoraggio, osservazione e piattaforma container
  • Certificato Amministratore Kubernetes (CKA) o certificazione CKAD
  • Esperienza nella fornitura di infrastrutture o progetti di trasformazione cloud in ambienti aziendali regolamentati
  • Forte capacità di analisi, gestione degli stakeholder e collaborazione di progetti
  • Eccellente capacità di comunicazione in inglese
