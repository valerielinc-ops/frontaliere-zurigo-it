Responsabilità principali

  • Contribuisci all'implementazione di zone di atterraggio cloud, pratiche DevSecOps e iniziative di ingegneria della piattaforma che accelerano l'adozione del client del cloud in scala.
  • Sfidare lo status quo, procurare informazioni necessarie e ideare soluzioni creative ed efficienti.
  • Applicare e aggiornare continuamente le tue conoscenze sulle migliori pratiche nella tecnologia cloud (DevOps, SRE, Platform Engineering), metodologie ingegneristiche, strategie di consulenza e condividere attivamente le conoscenze all'interno del team.

Requisiti principali

  • Tenere una laurea (bachelor / master / diploma) in informatica, tecnologia dell'informazione, ingegneria, o una disciplina relativa.
  • Esperienza di lavoro Possess in ingegneria cloud, gestione delle infrastrutture, DevOps o architettura di sistema (compreso il lavoro di progetto o la tesi rilevanti).
  • Esperienza pratica e certificazione in una o più principali piattaforme cloud– Microsoft Azure è preferito, mentre l'esperienza con AWS o Google Cloud è anche preziosa.
  • Esperienza pratica con Infrastructure-as-Code (ad esempio Terraform, Bicep, ARM), tooling CI/CD (ad esempio Azure DevOps, GitHub Actions, GitLab) e linguaggi di scripting/programming (ad esempio PowerShell, Python, Bash).
  • Familiarità con la containerizzazione e l'orchestrazione (Docker, Kubernetes / AKS), cloud networking, identità (Entra ID), e cloud sicurezza fondamentali.
  • L'esposizione a Microsoft Cloud Adoption Framework (CAF), Well-Architected Framework (WAF) è un plus.
  • L'interesse per argomenti adiacenti come AI/GenAI su cloud, FinOps o piattaforme di dati è benvenuto.
  • Abilità di problem solving particolarmente orientate, forti, con eccellenti capacità interpersonali, di ascolto e di comunicazione.
  • Proattivo ed entusiasta di promuovere valore e innovazione per i clienti.
  • Siete fluenti in inglese (il tedesco è un grande vantaggio) e sono disposti a viaggiare all'interno della Svizzera, e occasionalmente anche a livello internazionale.
